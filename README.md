# Business Card Generator

A browser-based business card designer with live preview, multiple themes, and export options.

**Live demo:** [tahagenc.com/tools/business-card](https://tahagenc.com/tools/business-card)

## Features

- 8 color themes and 4 layout options
- Custom font selection
- Logo/photo upload with circle crop option
- QR code generation
- Double-sided cards (front + back)
- Export as PNG or PDF

## Tech Stack

Vanilla HTML5, CSS3, JavaScript — no dependencies, no build tools.
